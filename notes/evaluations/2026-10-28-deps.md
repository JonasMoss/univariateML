**Executed locally:** all 44 metadata density references resolved, and all corresponding p/q/r exports existed. This checks reference implementation against the declared formula, not the correctness of the declaration; locations were selected using reference quantiles. No new fitter validation was run.

At probabilities .01/.5/.99, all continuous p(q(p)) errors were ≤1.12e-15. For discrete laws the right test is F(Q(p)−1)<p≤F(Q(p)); all passed except sads Zipf (2/3 failures). Extreme-parameter grids checked logitnorm (mu ±100, sigma .01/100), Nakagami (shape .01/1/1000), Lomax (lambda 1e±8, kappa .01/1000), Burr (shapes .01–1000) and standardized t (nu 2.00001/5/1e6). ## Finite Zipf: alternatives and direct checks

**sads executed:** for N=10 and 1e6, s=1e-8/.5/1/10/1000 and x=1,2,N, log densities matched −s*log(x)−log(sum(exp(−s*log(1:N)))) to printed double precision. Its positive-power denominator can overflow internally at huge s, but these checks still gave correct log densities. It allocates/sums O(N); q constructs all N cumulative probabilities by repeated prefix sums, hence roughly O(N²). Large-N q/r were deliberately not executed. s=0 gives NaN; pzipf(1.5,10,1)=0 instead of F(1)=0.3414172. qzipf(.4,10,1)=1 although the correct quantile is 2. rzipf uses a shifted inverse scheme, so its apparent correctness cannot validate qml. [Issue #52](https://github.com/JonasMoss/univariateML/issues/52) explicitly rejects VGAM density accuracy; that historical claim was read, not reproduced against VGAM.

**Only complete non-sads/non-VGAM finite-support candidate found: tolerance::{d,p,q,r}zipfman**, with s and N unchanged and b=NULL (or 0). Source inspected, package not installed: ordinary density is the direct normalized power formula, but log=TRUE logs an already computed probability (underflow, e.g. x=10,s=1000). At N≥1e6 the quantile branch leaves probabilities below F(1e6), but above F(1), at its initialized value 1: N=1e6,s=1,p=.5 must have Q>1. It also extrapolates beyond the support for larger N. The sampler frequency-ranks its draws, changing category identities. Reject as a replacement. Release 3.0.0, 2024-04-17; imports plotly/MASS/stats4, no direct VGAM; recursive count not established because it was unavailable. Responsiveness unknown. These are source-derived findings, not executions of the installed package. [Source](https://raw.githubusercontent.com/cran/tolerance/master/R/zipfman.R), [DESCRIPTION](https://raw.githubusercontent.com/cran/tolerance/master/DESCRIPTION).

[zipfR](https://packages.oit.ncsu.edu/cran/web/packages/zipfR/index.html) 0.6-70 (2020-10-11), zero external hard dependencies, models lexical spectra; [its namespace](https://raw.githubusercontent.com/cran/zipfR/master/NAMESPACE) does not provide a drop-in finite Zipf d/p/q/r quartet. [gamlss.dist ZIPF](https://rdrr.io/cran/gamlss.dist/man/ZIPF.html) has infinite-support zeta with exponent mu+1; max.value is a search cutoff, not finite-support normalization. [zipfextR](https://cran.mirror.garr.it/CRAN/web/packages/zipfextR/index.html) directly imports VGAM and is disqualified. poweRlaw is not a drop-in finite-N quartet. The [CRAN distribution task view](https://github.com/cran-task-views/Distributions/blob/main/Distributions.md) and targeted searches supplied no further eligible full quartet; this is a bounded search, not an exhaustive proof.

Zipf recommendation: **add now S** for optional dependency handling, **add later M** for a vetted independent external provider/upstream fixes, **skip** substituting tolerance. No R d/p/q/r should be added here under the ML-only policy. If the author requires immediate functional d/p/q/r with zero VGAM, the current external-provider policy and researched providers do not supply that outcome; report that limitation explicitly. s=0 can be represented by the existing discrete-uniform model (use mldunif), but backend switching must be explicit rather than passing zero to sads.

## Per-distribution notes

The first table and package table jointly specify references, maintenance, dependency weight and recommendation. Each density stem has the corresponding p/q/r exports (verified); e.g. extraDistr::dlomax means dlomax/plomax/qlomax/rlomax. Parameters below follow README/reference names; optional reference evaluation changes no MLE mathematics. S means a localized dependency/guard change, M a new backend validation or numerical-policy change, L a broad replacement. All models already exist, so “add now” means the dependency change, not adding a fitter. Unless already fixed/fixable, suggested fixed parameters below require metadata and adapter work.

**`mlbeta` — stats::dbeta (shape1, shape2).** Two shapes; solve digamma scores with a one-dimensional profile/Newton; moment starts, O(n+iterations). Constant data collapse to a point mass.

**`mlbetapr` — extraDistr::dbetapr (shape1, shape2).** Shapes shape1/shape2; transform x/(1+x) to beta and solve its scores; O(n+iterations). This reference has unit scale.

**`mlbinom` — stats::dbinom (size, prob).** size/prob; integer size profile with prob=mean(x)/size, compare Poisson face. size is already fixable; sample-max support constraint matters.

**`mlburr` — actuar::dburr (shape1, shape2).** shape1/shape2, unit scale; profile shape1=n/sum(log1p(x^shape2)), Newton in shape2; compare Pareto face at lower endpoint 1. O(n) per step.

**`mlcauchy` — stats::dcauchy (location, scale).** Location/scale; nonlinear likelihood with multiple stationary points, iterative search. A repeated value with multiplicity greater than n/2 gives unbounded likelihood by scale collapse; equality needs separate treatment.

**`mldunif` — extraDistr::ddunif (min, max).** Integer min/max are sample extrema; closed form, O(n). A constant sample is a legitimate one-point discrete uniform.

**`mlexp` — stats::dexp (rate).** rate=1/mean(x), O(n); all-zero data have an unattained point-mass supremum if zero were admitted.

**`mlfatigue` — extraDistr::dfatigue (alpha, beta, mu).** alpha/beta with mu fixed at zero by default; profile alpha using means of x-mu and its reciprocal, solve beta in 1-D. mu is already fixable; freeing a support endpoint requires a separate existence analysis.

**`mlgamma` — stats::dgamma (shape, rate).** shape/rate; rate=shape/mean(x), solve log(shape)-digamma(shape)=log(mean(x))-mean(log(x)); O(n+iterations), moment start. Constant sample has unbounded concentration.

**`mlged` — fGarch::dged (mean, sd, nu).** mean/sd/nu; multistart BFGS plus exact Laplace face and uniform comparison. nu is constrained to ≥1 in current README, unlike the older note. Unrestricted nu>0 has unbounded likelihood (Tumlinson); O(n) per objective.

**`mlgeom` — stats::dgeom (prob).** prob=1/(1+mean(x)); O(n). All zeros give the attained point mass at zero.

**`mlgompertz` — extraDistr::dgompertz (a, b).** a/b; profile a=nb/sum(expm1(b*x)), solve b>0; b→0 is exponential. O(n) per Newton step; compare boundary rather than accepting a tiny b.

**`mlgumbel` — extraDistr::dgumbel (mu, sigma).** mu/sigma; profile mu through exponential sums, solve positive sigma; moment start, O(n) per step. Constant sample has scale collapse.

**`mlhnorm` — extraDistr::dtnorm (mu, sigma).** mu=min(x), sigma=sqrt(mean((x-mu)^2)); O(n). Argument map mean=mu, sd=sigma, a=mu is essential. extraDistr excludes the endpoint, so the adapter uses its preceding floating-point value.

**`mlinvburr` — actuar::dinvburr (shape1, shape2).** shape1/shape2, unit scale; profile shape1 then scalar solve; shape2→infinity with shape1*shape2 fixed gives power on (0,1). Compare the fitted power face; O(n) per step.

**`mlinvgamma` — extraDistr::dinvgamma (alpha, beta).** alpha/beta; fit gamma to 1/x, including the Jacobian in logLik. Scalar shape Newton, O(n+iterations); no nondegenerate escape is needed for generic data.

**`mlinvgauss` — actuar::dinvgauss (mean, shape).** mean=mean(x), shape=1/(mean(1/x)-1/mean(x)); O(n). A Lévy limit exists in the closure, but does not beat the interior maximum for ordinary positive nonconstant samples.

**`mlinvweibull` — actuar::dinvweibull (shape, rate).** shape/rate; Weibull fit to 1/x with Jacobian; scalar shape solve, O(n) per step. rate here is inverse-Weibull rate, not scale.

**`mlkumar` — extraDistr::dkumar (a, b).** a/b; b=-n/sum(log(1-x^a)), solve profile in a. Profile tends to minus infinity at both ends for nonconstant interior data; O(n) per Newton step. Constant sample can concentrate without bound.

**`mllaplace` — extraDistr::dlaplace (mu, sigma).** mu is a sample median, sigma=mean(abs(x-mu)); O(n) selection or O(n log n) sorting. Even-sample medians need not be unique; constant sample diverges.

**`mllgamma` — actuar::dlgamma (shapelog, ratelog).** shapelog/ratelog; gamma MLE of log(x), support x>1, and Jacobian 1/x. O(n+iterations). This is actuar loggamma, not a real-valued log-gamma location family.

**`mllgser` — extraDistr::dlgser (theta).** theta solves -theta/((1-theta)*log(1-theta))=mean(x); Lambert-W/profile or Newton, O(n+iterations). All ones approach theta=0, outside its declared open domain.

**`mlllogis` — actuar::dllogis (shape, rate).** shape/rate; logistic fit on log(x), with shape=1/log-scale and rate=exp(-log-location). O(n) per step; constant sample concentrates.

**`mllnorm` — stats::dlnorm (meanlog, sdlog).** meanlog=mean(log(x)), sdlog=population SD of log(x), O(n). Constant sample has unbounded likelihood as sdlog→0.

**`mllogis` — stats::dlogis (location, scale).** location/scale; smooth numerical likelihood, moment start, O(n) per step. Constant data collapse; an optimizer return alone is not a proof of convergence.

**`mllogitnorm` — logitnorm::dlogitnorm (mu, sigma).** mu/sigma are normal parameters of logit(x); closed-form transformed normal MLE plus Jacobian, O(n). Density formula is normal(logit(x))/(x*(1-x)); constant sample diverges.

**`mllomax` — extraDistr::dlomax (lambda, kappa).** lambda is rate, kappa shape; kappa=n/sum(log1p(lambda*x)), scalar Newton in lambda, O(n) per step. lambda→0, kappa→infinity with product fixed gives exponential. Current moment gate is code behaviour, not a new global proof.

**`mllst` — extraDistr::dlst (mu, sigma, df).** mu/sigma/df, scale rather than SD, df≥1; multistart grid/EM/BFGS, compare Cauchy and normal. Current fitter rejects n<3 and multiplicity ≥n/2; unrestricted df>0 permits unbounded collapse. df is a useful prospective fixed parameter.

**`mlnaka` — nakagami::dnaka (shape, scale).** shape m>0 (also below 1/2), scale=mean(x^2); gamma shape equation on x^2, scalar Newton, O(n+iterations). Constant amplitudes concentrate. Package scale is E[X^2], not gamma scale.

**`mlnbinom` — stats::dnbinom (size, prob).** size/prob; profile prob=size/(size+mean(x)), solve size, compare Poisson as size→infinity. size is already fixable. All zeros give a nonidentified attained prob=1 boundary.

**`mlnorm` — stats::dnorm (mean, sd).** mean and population SD; O(n). Constant data have unbounded likelihood as SD→0.

**`mlparalogis` — actuar::dparalogis (shape, scale).** shape/scale, Burr with equal shapes; two-dimensional BFGS with log-data/moment starts, O(n) per objective. Both parameters are now fitted. Constant samples can concentrate; no complete closure classification established in this audit.

**`mlpareto` — extraDistr::dpareto (a, b).** b=min(x), a=n/sum(log(x/b)); O(n). Constant samples give a→infinity and unbounded continuous likelihood; b is an obvious prospective fixable endpoint.

**`mlpois` — stats::dpois (lambda).** lambda=mean(x); O(n), including attained lambda=0 for all-zero data.

**`mlpower` — extraDistr::dpower (alpha, beta).** alpha=max(x), beta=n/sum(log(alpha/x)); O(n). Constant sample gives unbounded beta. alpha is a natural prospective fixed upper endpoint.

**`mlrayleigh` — extraDistr::drayleigh (sigma).** sigma=sqrt(mean(x^2)/2), O(n); no shape search or reference package is needed for fitting.

**`mlsged` — fGarch::dsged (mean, sd, nu, xi).** mean/sd/nu/xi; standardized Fernandez–Steel family. Multistart BFGS, skew-Laplace, uniform and reflected half-GED comparisons; O(n) per objective plus face searches. nu<1 unrestricted fitting is unbounded (Tumlinson); half-GED has no public mlX.

**`mlsnorm` — fGarch::dsnorm (mean, sd, xi).** mean/sd/xi are standardized moments/skew, not mode/scales. Exact scalar profile; compare right translated half-normal (use mlhnorm) and reflection (fit mlhnorm(-x)). Nonexistence has positive probability; constants collapse.

**`mlsstd` — fGarch::dsstd (mean, sd, nu, xi).** mean/sd/nu/xi, nu>2; multistart BFGS and boundary comparisons. Use mlsnorm at nu→infinity; further half-normal face uses mlhnorm (reflect if needed). Half-t and two-piece t2 have no public mlX. These numerical comparisons do not certify the global maximum.

**`mlstd` — fGarch::dstd (mean, sd, nu).** mean/sd/nu>2; BFGS, normal and infinite-variance t2 comparisons. nu→2 can leave no finite SD parameter even with a finite limiting density. nu would be useful fixed; retain generic tie/scale-collapse precautions.

**`mlunif` — stats::dunif (min, max).** min/max are sample extrema, O(n); constant sample has interval length→0 and unbounded likelihood.

**`mlweibull` — stats::dweibull (shape, scale).** shape/scale; profile scale=(mean(x^shape))^(1/shape), scalar Newton with log-data starts; O(n) per step. Constant sample concentrates.

**`mlzip` — extraDistr::dzip (lambda, pi).** lambda/pi; positive-count truncated-Poisson scalar equation, then zero mass. Underdispersion can select pi=0 (Poisson, an included member); all zeros permit pi=1 with arbitrary lambda. O(n+iterations).

**`mlzipf` — sads::dzipf (N, s).** N=max(x) minimizes the normalizer. With T=mean(log(x)), score/n=E_s[log K]-T and curvature/n=-Var_s(log K). Thus the interior root is unique for N>1 when 0<T<E_0[log K]; otherwise s=0 maximizes when T≥E_0[log K]. All ones permit N=1 and arbitrary s. Bracketed Newton from s≈1, O(n+N*iterations), O(N) current storage; N/s are prospective fixable parameters.
