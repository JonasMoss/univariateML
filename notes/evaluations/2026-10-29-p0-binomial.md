# P0 binomial-type analysis — incomplete working record

Status: **partial, not a completed M1 oracle**. Several classifications use
conjectured compactifications and must not be converted to schema assertions. No claim here treats a numerical search as a
proof. Samples are nonempty, integer, and feasible with positive likelihood;
values incompatible with held parameters require a separate input error. For
C6, `N` is population size, `m` successes/white balls, and the reference's
`n = N - m`. The symbols `n_s` and `V` below denote sample size and population-form
sample variance. An unidentified parameter can still have an attained MLE.

`Y` = master accepts the indicated hold set; `N` = does not; `P` = partial
(including a declared limit, numerical failure, or special unidentified cases).
The master column is based on source inspection,
not a completed hold-by-hold numerical comparison.

## bbinom

| Held | Class, conditions, limit | Master |
|---|---|---|
| ∅ | data-dependent: see BB rule below; point/two-point, binomial and negative-binomial faces compete | N |
| size | data-dependent for size ≥ 2; all 0 or all size: point mass; endpoint-only mixed: two-point law; otherwise binomial face may win; global profile comparison required | P |
| alpha | data-dependent: all 0 attained; constant positive sample escapes to a point mass; otherwise compare the finite profile with the negative-binomial face of fixed shape alpha (BB below) | N |
| beta | data-dependent: all zero attained at size 0; an all-equal positive sample escapes to its point mass; otherwise a finite MLE exists | N |

Size zero gives an attained point mass at zero with unidentified shapes;
master rejects it as unidentified. Size one with both shapes free is an
attained Bernoulli likelihood, although its concentration is unidentified;
master rejects it. The compactification of the joint shape profile includes
the binomial and endpoint-two-point faces, but which wins is not determined
by the variance alone in this record.

At size 0 the single support point gives an attained likelihood, all remaining
parameters unidentified. At size 1, nu is unidentified; with prob free, all Bernoulli samples
have an attained MLE, including endpoints. Master
rejects size 0, and assigns nu = 1 for size 1.

## Integer-profile conditions

Define A_j as the *maximum likelihood*, rather than log likelihood, after
fixing the free size or population N to integer j and optimizing the remaining
free coefficients under the stated holds. In the families below each A_j is
attained. For each case define B as the maximum of the limiting likelihood
specified below. The proposed test is **there exists j with A_j ≥ B**: then a
finite global maximum exists; otherwise B is the unattained supremum. Equality
is essential. This is a condition on the data, not a finite-grid algorithm.
For zero-only and appropriate constant samples use the attained point masses
noted in the family tables. The condition is practical only if the infinite
integer profile can be certified; the supplied scans are not a certificate.

- `zib`, `zmbinom`, `ztbinom`, with size free and prob free: B is respectively
  the ZIP, zero-modified Poisson, or zero-truncated Poisson maximum, preserving
  a held pi/p0. The degenerate lambda = 0 case must use the corresponding
  limiting law, including the truncated point mass at one. A_j is attained on
  each compact fixed-size parameter set; the only positive-likelihood size
  escape is size → ∞, prob → 0, with size × prob finite.
- `hyper`: for held k, B is the binomial(k, p) maximum; for held m it is
  binomial(m, p); with neither held it is the supremum over binomial sizes and
  probabilities, including the Poisson limit. Interchanging m and k leaves
  `dhyper` unchanged. Given N, the admissible parameter grid is finite.
- `nhyper`: for held positive r, B is the likelihood maximum for r plus a
  negative-binomial(r, p) variable; with r free, maximize over integers
  1 ≤ r ≤ min(x), with the r = 0 degenerate case handled separately. With
  fixed m, the finite-size tail vanishes for r > 0, so the finite profile
  attains its maximum. The C6 compactification argument is given below.

T for `tbinom`: optimize a free lower bound to min(x)-1 and a free upper bound
to max(x), without changing the support elsewhere. If prob is free and data
are nonconstant, B is the best Poisson likelihood conditioned on the resulting
bounds (including fixed bounds), and use the integer-profile test above; for
constant data size = x and prob = 1 attain likelihood 1 (size = 0 handles
all-zero data). If 0 < prob < 1 is held, as size grows the conditional mass
at bounded observations vanishes, except when the effective upper truncation
U is finite, in which case it concentrates on U. Thus a nonconstant sample
has a finite optimum; a constant sample escapes exactly when it equals U and
no admissible finite choice of the free bounds makes the support a singleton.
At prob 0 or 1, apply positive-likelihood feasibility separately. These
compactification arguments also need independent verification.

BB (conjectured, requires a proof that the listed faces exhaust all size → ∞
paths): all zero is attained at size 0. With neither shape held, a constant
positive sample or mixed {0,b}, b > 1, escapes to a point/endpoint mixture;
{0,1} is attained at size 1. For all other nonconstant samples, let B be the
larger of the best binomial likelihood over integer sizes and the best
negative-binomial likelihood (including its Poisson face). A finite MLE exists
iff a finite beta-binomial parameter point has likelihood ≥ B. With alpha
held and a nonconstant sample, B is the negative-binomial maximum with size
alpha; use the same inequality. The finite-size binomial faces are included
in B because concentration → ∞ can occur at any fixed size. A strict excess
ensures that the maximum is attained; equality requires an actual finite point
with that value. These criteria are not certified by the finite-grid probes.

CMB: the reference caps size at 10^7, so no true size → ∞ escape is possible
under literal R7. With prob held strictly inside (0,1), at each admissible
size the nu → +∞ face concentrates on the centre(s), with weights determined
by held prob, and nu → −∞ concentrates on {0,size}, likewise. Let B be the
largest likelihood across all these faces and all admissible sizes. A finite
MLE exists iff a finite (size,nu) point has likelihood ≥ B. With free prob,
nu → +∞ can produce an arbitrary mixture of adjacent points and nu → −∞ an
arbitrary endpoint mixture. Any sample with three distinct values gives zero
likelihood on these faces; the stated two-point rules follow by comparison to
the saturated two-point likelihood. If the size cap is intentionally removed,
additional infinite-size limits must be analyzed; a CMP or geometric limit
can arise and the bounded-size classification cannot be carried over.

## Arguments and evidence

DeRiggi, “Unimodality of Likelihood Functions for the Binomial Distribution,”
JASA 78 (1983), 181–183, [doi:10.1080/01621459.1983.10477949](https://doi.org/10.1080/01621459.1983.10477949),
states that the two-parameter binomial MLE exists exactly when the sample mean
exceeds the sample variance and the profile derivative has at most one finite
root. The all-zero attained degeneracy is handled separately.

**Proved here.** For hyper with N → ∞, pass to a subsequence: if m or k is
bounded, fix that integer and let the other divided by N converge; the limit
is the corresponding binomial. If both diverge and mk/N remains bounded,
both sampling fractions vanish and factorial moments give a Poisson limit.
If mk/N → ∞, hypergeometric variance is at most its mean, so Chebyshev's
inequality sends the probability of every bounded count to zero. Thus no
other positive-likelihood face is missed. For nhyper, r is bounded by min(x);
fix r on a subsequence. If m/N → p > 0, the sequential drawing probabilities
converge to a negative binomial in x-r; if p → 0, the probability of a
bounded stopping time vanishes for r > 0. At p = 1 the limit is the point
mass at r. For fixed m and r > 0, p → 0. Degenerate r = 0 is separate.
At each finite N the admissible grid is finite. If some A_j exceeds B, the
limsup bound puts all but finitely many A_j below it, so a maximum is attained;
if A_j equals B, either it is a maximum or another A_j exceeds B and the same
argument applies. If none reaches B, the supremum is unattained.

A fixed finite integer domain yields a maximum of a finite
set whenever some member has positive likelihood. For fixed 0 < p < 1,
`dbinom(x, size, p)` tends to 0 for each fixed x as size → ∞. The same is
true after zero truncation since the truncation probability tends to 1; this
also proves the corresponding zero-inflated and zero-modified cases when
any positive observation occurs. All-zero data are handled by an attained
zero component. For fixed beta-binomial shapes, the beta-binomial probability
of every fixed count is O(size^(-alpha)), hence a positive likelihood is
attained at a finite size. Endpoint probabilities need separate feasibility
checks, as noted in the tables.

For fixed tbinom size and bounds the natural parameter is logit(p), its score
is n_s times sample mean minus conditional mean, and the derivative of the
latter is the conditional variance. The mean spans the two support extremes;
endpoint attainment depends on whether the original binomial assigns the
conditioning event positive mass there.

For cmb at fixed size, (x, log choose(size,x)) forms a full finite exponential
family. A finite joint natural parameter exists exactly when the empirical
sufficient statistic is in the relative interior of its convex hull. The
single-parameter cases follow from the analogous one-dimensional moment range.
These observations are also described in the family READMEs; beta-binomial
one-held-shape boundary claims rely on the source's likelihood-profile analysis
and are not independently proved here.

**Numerical checks.** `oracle.R` compares reference-density multistart fits
with master for fixed designs, plus finite integer enumeration for hyper and
nhyper. `binom-profile.R` profiles integer sizes against the Poisson face.
`held-checks.R` compares the implemented shape holds and checks the CMB formula
against `dcmb`; `size-scan.R` and `hyper-scan.R` scan every free-design hold
subset. `limits.R` records escaping paths. Output TSVs are saved beside the
scripts. These finite searches are diagnostic and do not establish global
optimality. Among returned finite fixed-design fits, all comparisons were within
1e-6 times sample size. The CMB formula agreed with the package density to
1.8e-14 in log density. The CMB endpoint rejection is a counterexample to
master agreement under R7. For x = (2,6,6), `mlbinom` returns size 6,
probability 7/9, logLik −6.826661; the independent density gives −6.215143
at size 11 and probability 14/33. Thus its returned fit is at least 0.6115
below a feasible parameter point. A second mismatch occurs for the n = 100
sample whose count table is saved in `master-free.tsv`; size 10 loses to 11 by
0.055278. At the returned sizes, the reference-density optimizer agrees with
master; the problem is the size selection, not the density evaluation.

**Missing:** independent proof that every divergent sequence is covered by the
stated beta-binomial and truncated-binomial limits; complete master-vs-oracle
comparisons for all implemented combinations; independent numerical evidence
for every limiting face, and comprehensive reference-domain checks. The
finite-grid optimizer is diagnostic and can miss a global maximum. A large
finite search is not evidence that a supremum at infinity is attained. No R5 collapse/spike/branch/endpoint shape
restriction is proposed for these discrete families; this agrees with the
design's absence of such restrictions. Infinite-design escapes are R6 cases.

These entries describe current master and are not intrinsic no-MLE holds; the
P1 schema should remove them as implementations land. In particular, no
blanket `no-mle` entry follows from data-dependent escapes.

R7: tbinom README lists a and b as `(-inf, inf)` whereas the reference accepts
`-Inf` and `Inf` (and defaults to them). CMB README says `prob` is in `(0,1)`
but `dcmb` accepts `[0,1]`, and lists unbounded size while `dcmb` caps it at
10^7. That hard cap changes the literal R7 free-size question; the escape
analysis above treats it as an implementation resource limit, which needs a
design decision. `extraDistr::dnhyper` can segfault at n = 0, including its
degenerate cases; our numerical oracle substitutes the exact point mass there.
The nhyper classifications use this natural completion, so literal R7 requires
a decision or a reference repair before those boundary conclusions can be applied. For other families, no complete
reference-domain audit is claimed. `extraDistr::dbbinom` at a zero shape gives
NaNs at boundary observations, so accepting some individual evaluations there
does not by itself establish a valid probability distribution at that shape.
