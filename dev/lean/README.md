# Lean formalization (pilot)

Machine-checked versions of selected likelihood theorems from the family dossiers. Conventions and layers:
[AGENTS.md](AGENTS.md). Mathlib v4.36.0 (Lean 4.36.0, `~/.elan`). `.lake/` is not tracked; to set it up elsewhere,
run `lake exe cache get` once.

Check everything with `lake build` from this folder.
