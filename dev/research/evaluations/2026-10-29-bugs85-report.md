## Mathematics and numerical checks

DeRiggi (1983), DOI 10.1080/01621459.1983.10477949, gives unimodality of
ordinary binomial profile likelihood. The numerical implementation uses
extended-precision differences, but their signs are not certified against
roundoff. Tests include independent R `dbinom` grid checks and C++ held-size
scans, plus the original size-13 reproducer.

The Rayleigh zero condition follows directly from its density; positive-data
R tests use a scalar optimization of the reference density. Triangular
constant-data tests check analytic endpoint solutions and reference density
values at several locations. GEV fixed-shape tests compare tied samples against
independent reference-density optimizations. Existing Kumar and Fréchet oracle
tests cover nonconstant data; added cases exercise the failure and tie paths.
