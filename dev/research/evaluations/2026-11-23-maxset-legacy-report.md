## Binding and validation contracts

`render_fit` treats a missing typed set on a known non-unique estimate as an adapter defect. It uses the same numerical evaluation failure and outcome override as a malformed set. It also requires exact first-row identity before exposing the set. The C++ regression supplies two comparison candidates and verifies the missing-set stop, then exercises the undetermined and valid typed outcomes. [Renderer](../../../bindings/common/fit.hpp#L201), [C++ regression](../../../univariateML-cpp/tests/test_comparison.cpp#L63)

R and JS emit `maximizers` for typed representatives and `candidates` for comparison evidence. The shared comparison helper takes the selected point supplied by its caller. The R print and summary path uses the canonical set description and keeps the documented generic notice for deserialized older objects. The R test helper keeps `estimates` through `coef()` and exposes the R comparison model as `model` to mirror JS. It drops the candidates-to-maximizers compatibility alias and the synthetic success `kind`. Documented family metadata such as Cauchy's `maximizer_support` and beta-binomial's `maximizer_shape_ray` and `free_positive_shapes` still describe their respective fits. [R converter](../../../bindings/r/scripts/common_fit.h#L130), [JS converter](../../../bindings/js/bindings.cpp#L76), [R printing](../../../bindings/r/R/code_helpers.R#L487), [R test helper](../../../bindings/r/tests/testthat/helper-render.R#L1)

`unique-false-needs-set` runs before the named-fixture filter, so it checks the archive and modifier records as well. It decodes the wire set, checks the coefficient names and membership, and compares the first representative with the estimate. The flat-maximum checks use typed representatives and keep their independent equality, likelihood and hold checks. The seven direct rule checks cover valid and corrupted records and the undetermined case. The fresh consistency run found zero failures and 114 ledger entries now passing. [Strict implementation](../../../dev/validation/fit-consistency.py#L220), [Rule checks](2026-11-23-maxset-legacy-data/check_rule.py), [Consistency output](2026-11-23-maxset-legacy-data/strict.txt)

## Open

- The private R window kernels can return infinite design bounds in their coefficient vector. Version 1 permits infinities as open interval endpoints and requires finite coordinates. Publishing a typed set for those private results would require separating the design from the returned coordinates or extending the wire contract. The current result preserves the estimate and its likelihood with `unique = NA`. Public window fits already carry the truncation design separately.
- The existing proof gaps for nonconstant hypergeometric swaps, beta-negative-binomial reflections and the unresolved Student-t symmetry cases still require exhaustive mode comparison or accurate isolation of all branches. Their comparison and stop contracts are covered by the earlier reports. [Count report](2026-11-23-maxset-count-report.md), [Continuous report](2026-11-23-maxset-cont-report.md)
