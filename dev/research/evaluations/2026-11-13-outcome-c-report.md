Field-dependent precedence:

- Snorm half-normal boundaries with an invalid limit payload map to `F(Evaluation)`: the mapper checks the same limit coefficients, likelihood and candidate bounds as the existing binding guard. The adapter retains the existing plain error when the payload cannot be represented. This covers double-only class `huge`, and is not a rejection of a core estimate.

- `accuracy_stop` selects `F(Tolerance)` or `F(Conditioning)` for EMG, folded normal, GB2, generalized gamma, Lomax, inverse Pareto, Pareto IV, Skellam and Student-t; Burr reads it on `NumericalFailure`. GB2 and Student-t additionally map `accuracy_failure` to `F(NoConvergence)` when no accuracy-stop reason is recorded.
- CMP uses the budget flag on failures, folded normal uses it after accuracy checks, Skellam uses it on search failures, and hyper/nhyper use it only on error statuses. Their successful uncertified fallbacks remain estimates even with a retained budget flag. Snorm checks unboundedness before budget, then comparison ties (`E(false)`).
- Beta-prime `BfgsFailure` first reads its accuracy-stop reason, then uses certificate Budget → `B`, comparison tie → `E(false)`, Arithmetic → `F(Evaluation)`, otherwise `F(Unresolved)`. Gamma/inverse-gamma boundaries lacking limit coefficients retain their plain error and map to `F(Evaluation)`. The unit-shape exponential limits inherit the Lomax likelihood-margin rule, hence `L(false)`; separated gamma/inverse-gamma faces use `L(true)`.
- Lomax uses certificate Budget/Arithmetic after accuracy and the exponential-limit branch. Inverse Pareto uses these certificate fields on `IterationFailure`. Kumar uses its certificate Budget flag. GPD uses Budget, Tie (`E(false)`), Arithmetic and ThresholdCollapse: finite `limit_loglik` gives `L(true)`, otherwise `N(Unbounded)`.
- GB2 TrGamma/InvTrGamma/Pareto/Power boundaries use `L(!limit_coef.empty())`: witnessed delegated/endpoint limits retain certification; payload-less paths, including the exploratory face-versus-search margin decision, are uncertified.
- EMG comparison ties on `IterationFailure` give `E(false)`. Student-t limits pass its flag; `NonUniqueHeldSd` gives `E(c,false)` for the proved symmetric maximizers. Hyper/nhyper adjacent ties and unidentified sets give `E(c,false)` under their computed-comparison contract; exploratory face ties give `E(false)`. Triangular `not_unique` is a likelihood-proximity warning, not proof of equality, so the dossier certification rule is retained without inferring proved nonuniqueness.

## Adapter information and type limitations

No adapter override of a core success was observed in either final snapshot (both outputs report `{}`). Existing post-core rejection guards now attach `overridden` when the raw status is `Ok`; their messages and other fields are unchanged.

The core result cannot reconstruct these retained adapter decisions:

- Beta-prime `InvalidStart` is `nomle` for positive constant data with both shapes free, otherwise a plain error. The adapter inspects data and hold flags and attaches `N(Unbounded)` only on that existing branch.
- Half-normal `DegenerateData` conflates empty/too-small input with scale collapse. The adapter uses caller data to attach `F(InvalidInput)` for empty/nonfinite observations; finite degenerate samples retain `N(Unbounded)`.
- CMP retains its existing fully-held rewrite of `BudgetLimit` to `NumericalFailure` with the budget flag cleared. Outcome attachment follows that rewrite, which is a diagnostic-cap policy rather than a rejection of a core success.
- Hyper `FaceUnresolved` and `FaceTie` have plain errors on the all-free exploratory route, versus `unresolved`/`tie` when a design/count is held. Suppressed exploratory stops attach `F(NoConvergence)` without calling them core-success defects.
- The retained `classify` guards in EMG, foldnorm, hnorm, invgamma, lnorm, pareto, rayleigh, snorm and triang also inspect input finiteness, constancy, controls or payload eligibility before assigning a kind. These checks are unchanged; neither final snapshot encountered a disagreement from them.

Open outside this job: the fixed shared reason vocabulary has no exact reason for an identically zero likelihood. Rayleigh `ZeroLikelihood` and hyper/nhyper `Infeasible` therefore use `N(Unattained)` as the nearest existing nonexistence reason to preserve their `nomle` classification; this does **not** claim their zero supremum is mathematically unattained. Kumar `Unbounded` remains the existing plain error and maps to `F(InvalidInput)`; GB2 LognormalBoundary/DoubleParetoBoundary remain plain errors and map to `F(Evaluation)`/`F(Unsupported)`. These legacy classifications are recorded, not repaired in this metadata-only job. No out-of-scope edits are required for this job; refining those reason/classification distinctions belongs to the shared-outcome follow-up.
