At fixed endpoints the mode log likelihood is convex between consecutive observations, so a free maximizing mode occurs at an observation. This gives a finite exhaustive candidate set, rather than multistart optimization. For a fixed mode the reciprocal endpoint coordinates give a concave objective. Its tangent over the coordinate box supplies an upper bound, including for unfinished pruning solves. The interval bounds only remove candidates below the incumbent; every visited finite candidate must converge or the final status is `IterationFailure`. The code enlarges the pruning bound by `1e-11*n*(1+abs(logLik)/n)` and uses `1e-10*n` separation. Endpoint Newton convergence uses the supplied dimensionless step tolerance, not a newly established likelihood-error bound. This certification concerns the global search structure in exact arithmetic conditional on computed comparisons; it is neither an outward-rounded floating-point guarantee nor a uniqueness claim. Constant samples prevented from collapsing by a held exterior mode use explicit endpoint maxima. The derivation and code are in `triang/README.md:106` and `triang/mle.hpp:19,107,150,199,236`.
