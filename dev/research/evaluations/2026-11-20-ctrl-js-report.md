## C++ test tolerance

The tests used `kFitTol` as a solver argument. It now requests relative coefficient accuracy of `1e-10`. A comparison to a correctly rounded nonzero normal binary64 reference allows `t + (1 + t) * u`, where `t = 1e-10` and `u = epsilon(double) / 2`. The factor `1 + t` converts the exact-maximizer denominator to the stored reference denominator using the triangle inequality. The resulting comparison threshold is about `1.00000111e-10`.

The table records the maximum absolute relative coefficient error across both workstation builds and all measured coefficients for the case. Exact zero coefficients have zero absolute error. Goldens use the stored independent high-precision reference fields. The outlier fixtures and the three-point Cauchy sample use independent 60-digit score solves, which provide numerical evidence. The held-scale logistic case uses its supplied high-precision location. The binomial boundaries have exact answers. The existing family assertions, including stricter golden comparisons and the checks of statuses, likelihoods, scores, equivariance, moments and sampling, retain their own thresholds.
