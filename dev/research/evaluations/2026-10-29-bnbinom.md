# Beta negative binomial: boundaries, identification and fitting

2026-10-29. Parameters below are `(r,a,b) = (size,alpha,beta)`.
This note separates proofs, numerical evidence and unresolved questions.

## Proved identities

Integrating NB(r,p) against Beta(a,b) gives

\[
f_x=\frac{\Gamma(r+x)\Gamma(b+x)\Gamma(a+r)\Gamma(a+b)}
 {\Gamma(r)\Gamma(b)\Gamma(x+1)\Gamma(a+r+b+x)\Gamma(a)}.
\]

The expression is unchanged by exchanging r and b. Alternatively, the
beta odds `(1-p)/p` have law `G_b/G_a`, so the Poisson mixing intensity is
`G_r G_b/G_a`, with independent unit-scale gammas. This proves the symmetry.
It is discrete label ambiguity, not a continuous nonidentification away
from the diagonal. On the diagonal the antisymmetric score vanishes.

At r=1 the mass is `B(a+1,b+x)/B(a,b)`, the two-parameter Waring law on zero-based counts.
At r=b=1 this reduces to `a B(x+1,a+1)`, so X+1 is Yule--Simon(a).
Gamma-ratio asymptotics give

\[
f_x\sim \frac{\Gamma(a+r)\Gamma(a+b)}
 {\Gamma(r)\Gamma(b)\Gamma(a)}x^{-a-1}.
\]

## Proved proper Hellinger closure

Pointwise convergence to a probability mass function implies total variation
and Hellinger convergence (Scheffe's lemma on counting measure).

* With r finite, a,b increasing and a/(a+b) tending to p in (0,1), the beta
  mixture concentrates and the limit is NB(r,p).
* Exchanging r and b gives the second NB route, with NB size b.
* With r,b,a increasing and rb/a tending to lambda in (0,infinity), the
  intensity converges in probability to lambda: the limit is Poisson(lambda).
* r or b tending to zero, with the other shapes fixed, gives delta_0.
  So does a tending to infinity with r,b fixed.
* a tending to zero with r,b fixed sends all mass to infinity: every fixed
  mass tends to zero. This is not a Hellinger limit in the probability simplex.
  On every nonempty fixed sample its likelihood tends to zero.

These exhaust proper boundary laws. To see the possible degenerations,
extract a subsequence along which each positive shape has a limit in
[0,infinity]. If r or b tends to zero, for fixed x>=1 the bound
`f_x <= (r)_x/x!` (or its mirror) forces f_x to zero; tightness then forces
delta_0. When r,b stay bounded away from zero, a tending to zero makes
all finite masses vanish. With a bounded and a numerator shape unbounded,
the gamma-product intensity diverges in probability. If a is unbounded:
both numerator shapes bounded give delta_0; exactly one unbounded yields
NB or delta_0 or escape to infinity according to its ratio to a; both
unbounded yield Poisson or delta_0 or escape according to rb/a. Gamma
concentration proves these statements, including ratios tending to 0 or
infinity. A defective limit when a numerator shape tends to zero may retain
some zero mass, but all positive fixed masses vanish; its likelihood tends
to zero on samples containing a positive count. Such defective limits cannot
improve on delta_0 for an all-zero sample.

| Held coefficients | Reachable nondegenerate faces | Other proper face |
|---|---|---|
| none | NB with free size; Poisson | delta_0 |
| r | NB with size r | delta_0 |
| b | NB with size b | delta_0 |
| a | none | delta_0 |
| r,a | none | delta_0 via b down to 0 |
| a,b | none | delta_0 via r down to 0 |
| r,b | none | delta_0 via a up to infinity |
| r,a,b | none | none |

There is no separately reachable Poisson face when either numerator shape
is held, since that gamma factor remains random.

## Proved existence statements and local tests

For all-zero data, every nontrivial free subset has an unattained delta_0
supremum. With every parameter held there is simply a finite likelihood.
For data containing a positive count and a held, or at least two parameters
held, the preceding subsequence classification makes positive-likelihood
upper level sets compact. A finite maximum therefore exists. No uniqueness
claim is needed for this argument.

In the remaining subsets, a finite candidate that strictly exceeds all
reachable NB/Poisson faces guarantees a finite maximum, by the same
compactness argument. Conversely, if all finite values are strictly below
the best boundary value, there is no finite MLE. Equality needs care:
an attained interior tie still constitutes an MLE mathematically; the
implementation deliberately awards numerical ties to the simpler face.

Put a=k p and b=k(1-p), holding r fixed. Expansion of the gamma ratios gives

\[
\ell=\ell_{NB}+\frac1{2k}\sum_i\left[
\frac{r(r-1)}p+\frac{x_i(x_i-1)}{1-p}-(r+x_i)(r+x_i-1)\right]+O(k^{-2}).
\]

At the NB fitted probability p=r/(r+m), m=mean(x)>0, the coefficient is

\[
\frac{nr}{2m}\left[v-m-\frac{m^2}{r}\right],\qquad
v=n^{-1}\sum_i(x_i-m)^2.
\]

Positive sign proves an inward improvement. At a free-size NB maximum,
profiling r and p does not change this first derivative (envelope theorem).
Negative sign establishes local boundary optimality only, not global escape;
zero sign needs higher order terms. The mirror has the same test.
Consequently, for a positive-mean sample, if its best reachable NB face
has a finite size r and this coefficient is strictly positive, a finite
BNB maximum exists: there is an interior value above that face, and the
free-size NB face already dominates Poisson. This is a sufficient sample
condition, not a necessary one.

At the Poisson corner the leading variance-of-intensity perturbation has
sign v-m. Thus strict overdispersion improves on Poisson, but need not
improve on NB. Underdispersion makes Poisson locally optimal. A general
proof that v<=m forces global Poisson optimality in this family is **open
here**; the fitter does not use such a shortcut.

Nonexistence has positive probability under every finite parameter vector:
P(all zero)=f_0^n>0. This includes all fixable subsets with a free parameter.
For an all-positive constant sample k, any Poisson mixture satisfies
`f(k)<=max_lambda Pois(k;lambda)=Pois(k;k)`. Equality requires constant
intensity k, so the all-free supremum is Poisson(k), unattained in the
finite family. This event also has positive probability. Another proved Poisson-escape
class is nonconstant data supported on {0,1}. Write m in (0,1) for the sample
mean. For any Poisson intensity mixing law, Jensen gives
`(ell_mix-ell_Pois(m))/n <= log(E[exp(m-Lambda)*(1-m+Lambda)]) <= 0`,
since `exp(m-lambda)*(1-m+lambda)` has unique maximum 1 at lambda=m.
Equality requires degenerate intensity, unavailable at finite BNB shapes.

## Mirror and global shape: proved versus open

Every off-diagonal maximum has a swapped companion. Folding at r<=b removes
that duplicate. The diagonal can maximize the likelihood: numerical examples
below support this; a proof for a particular finite sample would need a
global certificate. Symmetry by itself neither excludes a diagonal maximum
nor proves unimodality after folding. Folded unimodality and uniqueness for
the full three-parameter family remain **open here**. The numerical algorithm
uses diagonal and asymmetric starts and makes no such assumptions.

## Verified literature

Irwin's [Part I (1975), JRSS A 138, 18--31](https://doi.org/10.2307/2345247)
defines the generalized Waring law through its hypergeometric generating
function; Part II describes negative binomial limits
([doi:10.2307/2984648](https://doi.org/10.2307/2984648)). His notation maps
`(a,k,rho)` to our `(r,b,a)`.

[Xekalaki (1984), JRSS A 147, 488--498](https://doi.org/10.2307/2981580)
explains why the two nonrandom variance components cannot be separated
from univariate data and introduces a bivariate extension. The
[GWRM reference manual](https://stat.ethz.ch/CRAN/web/packages/GWRM/refman/GWRM.html)
also describes the interchangeable shapes, and numerical fitting by
nlm/Nelder--Mead followed by L-BFGS-B. It supplies no full-family global
existence or uniqueness theorem in the inspected documentation.

Tang, Wang and Zhu (2023), [On the MLE of the Waring distribution](https://doi.org/10.1080/24754269.2023.2176608),
Statistical Theory and Related Fields 7(2), 144--158, give necessary and
sufficient existence conditions and uniqueness for the **two-parameter**
Waring subfamily. The abstract and discussion of their profile intersections
were verified; no extension to three free parameters is inferred here.

## Numerical evidence and reproducibility

The independent R oracle in `distributions/bnbinom/test.R` aggregates counts,
uses literal lgamma/lbeta masses, and runs bounded nlminb from 12 starts in
log parameters. Bounds +/-12 prevent cancellation-induced false maxima at
huge shapes. It does not use the fitted point as a start. The external
extraDistr mass is cross-checked separately. Bounds are a numerical work
restriction, not a mathematical existence proof. The C++ search uses up to
30 starts, log shapes in (-28,28), extended-precision gamma increments,
and an independently evaluated score gate. Neither search certifies a global
maximum. True NB and Poisson fits are evaluated separately; no large finite
BNB parameters stand in for a face.

R seed 4821: 1200 draws from (.7,1.8,6) fit approximately
(.7071,2.0763,6.7353). Every held subset is compared with the independent
oracle. Standalone gamma-product seeds 1--12, n=1000 from (1,2,5), all
returned finite off-diagonal fits; this is evidence, not a uniqueness result.

The independent oracle gives golden-seed 13086 log likelihood
-1275.6474863695578; the C++ golden gives -1275.6474863695587.
For 20 zeros and 20 fives, m=2.5 and v=6.25: the fitted NB size is
0.493768, the inward coefficient is approximately -35.187, and NB log
likelihood is -82.10764. The bounded independent BNB oracle approaches
-82.10782 from below. Both searches select the NB face. Analogous samples
with positive count 3, 10 or 20 also select NB. This demonstrates numerical
overdispersed escape, not a theorem inferred from a negative local score.

Gamma-product sampling with std::mt19937_64 seed 1, n=500, true (1,2,1)
returns approximately (1.22131,2.38886,1.22131), log likelihood -660.610,
compared with NB -674.085. Diagonal fits also occur at seeds 2,4,7,9.
Seeds 3,5,6,8,10 give asymmetric pairs. No assertion of folded unimodality
is based on these runs. Independently sampled R seeds 1--8 from the same
law all gave asymmetric fits; the RNG streams are different.

Underdispersed samples consisting of 999 tens and one count in
{20,30,50,100} all select Poisson. These stress tests do not settle the
general underdispersion question.

The rerunnable R exploration script is
`dev/research/evaluations/2026-10-29-bnbinom-oracle.R`. Standalone numerical probes
