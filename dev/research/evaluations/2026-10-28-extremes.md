## Generalized extreme value

### Reference implementations and numerical checks

Use maxima convention: z=(x−μ)/σ, t=1+ξz>0, σ>0; F=exp(−t^(−1/ξ)), and log f=−log σ−(1+ξ)log1p(ξz)/ξ−exp(−log1p(ξz)/ξ). At ξ=0 this is the ordinary maxima Gumbel. **Positive ξ means heavy right tail**; do not import the opposite shape sign from other conventions.

extraDistr supplies **dgev/pgev/qgev/rgev**, arguments `mu, sigma, xi`; all four use this convention. Its log density uses `log1p`, a useful advantage over naive powers. [Implementation](https://raw.githubusercontent.com/cran/extraDistr/master/src/gev-distribution.cpp).

**Checked here:** μ=0, σ=1, x∈{0.1,0.5,1}, ξ∈{−0.75,−0.5,0,10^−12,0.3,10}. Log-density differences against the stable formula were ≤2.3×10^−16. Direct ordinary-density powers agreed to ≤1.2×10^−16 away from tiny ξ; direct powers themselves lose accuracy near zero and are not a trustworthy oracle there. At ξ=−0.5, x=2−10^−12, log density ≈−28.3240794; at ξ=0, x=1000 it correctly remains −1000.

For p∈{10^−12,0.01,0.5,0.99,1−10^−12}, max |pgev(qgev(p))−p| was ≤1.4×10^−17 for ξ=−0.75,0,0.3, but **2.87×10^−5 at ξ=10^−12**, and 2.99×10^−12 at ξ=10. At ξ=10^−16, qgev(0.5)=0 instead of approximately 0.366512921. The quantile uses a subtractive `pow(...)−1` expression. `qgev(1,xi=-0.5)` returns **Inf instead of endpoint 2**. Upper log probability at x=1000, ξ=0 is **−Inf instead of approximately −1000**: the wrapper complements an already rounded CDF. These are evaluation defects, not fitter failures.

Alternatives, by **source inspection**:

- **evd** has d/p/q/rgev (`loc,scale,shape`), `fgev` for ML. Its density forms `1+shape*z` then takes a logarithm; q/r use subtractive powers, p/q have no `log.p`, and q rejects p=0 or 1. Thus it is a lightweight ordinary-range reference, not an automatic cure for tiny-shape/tail defects. [Source](https://raw.githubusercontent.com/cran/evd/master/R/uvdist.R).
- **ismev** supplies `gev.fit`, diagnostics and likelihood machinery rather than a conventional public d/p/q/r quartet. It is a fitting comparator, not the proposed density provider. [Package](https://cran.r-project.org/package=ismev).
- **extRemes** has `devd/pevd/qevd/revd(type="GEV")`, with `loc,scale,shape`. The source uses direct powers and subtraction in q and several tail paths; q rejects endpoints. Its GP log-probability branches also appear reversed: with default `lower.tail=TRUE`, GP shape zero returns −q rather than log(1−exp(−q)); this is a source-derived defect, not runtime-tested here. Prefer neither its evaluator nor its heavier dependency tree for this job. [Source](https://raw.githubusercontent.com/cran/extRemes/master/R/distfuns.R).
- **mev** has d/p/q/rgev (`loc,scale,shape`), small-shape approximations, explicit quantile endpoint handling, and `expm1` for GEV survival probabilities. This is the strongest candidate among these for GEV numerical cross-validation, but not uniformly tail-safe: q converts upper probabilities through `1-p`, and log survival can still underflow. `fit.gev` and analytic scores/information are useful independent fitting checks. [Distribution source](https://raw.githubusercontent.com/cran/mev/master/R/distributions.R), [author's fitting discussion](https://lbelzile.github.io/mev/articles/01-univariate.html).
- **POT** primarily covers GPD/threshold models; it offers no competing GEV quartet worth adding as the GEV reference.

### MLE behaviour: literature versus derivation

**Literature:** [Smith (1985), DOI 10.1093/biomet/72.1.67](https://doi.org/10.1093/biomet/72.1.67) studies endpoint-dependent nonregular estimation. The conventional regimes are ξ>−1/2 (regular), −1<ξ≤−1/2 (nonregular, equality needs separate asymptotics), and ξ<−1 (upper-endpoint divergence). For GEV, [Bücher–Segers (2017), DOI 10.1007/s10687-017-0292-6](https://doi.org/10.1007/s10687-017-0292-6) provides rigorous regular asymptotics. Its [proof text, §3](https://dial.uclouvain.be/pr/boreal/object/boreal:171497/datastream/PDF_01/view) explicitly distinguishes local maxima from global maximization on compact parameter sets. These results must not be read as finite-sample global existence over all ξ>−1.

**Derived here, upper endpoint:** fix ξ<−1 and move endpoint e=μ−σ/ξ down to M=max x, holding other quantities nondegenerate. At each maximum observation, f∝(e−M)^(−1/ξ−1); the exponent is negative, so log L→+∞. This occurs for every finite nonconstant sample, regardless of its generating shape. At ξ=−1, X is a **reversed translated exponential**, with finite nonzero endpoint density, not a uniform.

**Derived here, positive-shape collapse:** set μ=m=min x, fix ξ>0 and let σ↓0. If m occurs k times, its density factors contribute σ^(−k); each other factor contributes σ^(1/ξ). Hence

`L ~ C * sigma^((n-k)/xi-k)`.

It diverges whenever **ξ>(n−k)/k**. Thus **even restricting ξ≥−1/2 leaves the unrestricted GEV global ML problem ill posed**. Runtime example x=(0,1,2,3), ξ=4: log L=−6.31967, −1.53239, 8.83108 at σ=10^−4,10^−12,10^−30. This is a separate collapse mechanism, not Smith's negative-shape endpoint argument and not an ordinary Hellinger density escape.

**Proposed policy:** add later with a declared bounded shape interval, e.g. **−1/2≤ξ≤1**, n≥3 and largest tie multiplicity <n/2. The tie guard makes the collapse exponent strictly positive for every allowed positive ξ, even if location approaches any repeated observation. This is a conservative constrained family, not a theorem that ξ>1 is scientifically invalid. The lower bound is stronger than needed for bounded endpoint likelihood: a floor strictly above −1 would suffice there. At exactly −1/2, do not claim usual regular inference. Both finite shape bounds are attained boundary fits, with constrained scores, not D1 escapes. Alternatives preserving more shapes need their own existence analysis; do not silently install a sample-dependent upper bound.

Gumbel ξ=0 is already in the continuous family. A finite optimum at zero must be returned (or delegated when shape is explicitly fixed), **not stopped as “Use mlgumbel”**. No uniform face arises from a finite GEV shape. On the proposed bounded interval, the problematic unbounded-shape paths are excluded; ordinary nondegenerate Gumbel/Fréchet/reversed-Weibull cases are members, not extra limit models. Constant samples have scale-collapse degeneracy.

### Fitter sketch and recommendation

Estimate μ, σ, ξ; allow each to be fixed. Use log σ, a support-feasible parametrization or rejected infeasible steps, and direct evaluation of both closed shape bounds (a logistic transform alone misses them). Fit Gumbel first; add quantile-based scale/location starts and a small shape grid, then BFGS with support-aware line search. Stable likelihood uses `log1p(ξz)/ξ` with a controlled ξ=0 expansion. Each objective is O(n); multistart three-dimensional optimization dominates cost. C++ statuses handle invalid data, bounds, and failure without exceptions. No generally closed-form joint fit or uniqueness claim.

**Add later, L.** First resolve the constrained-model decision and upstream evaluator defects. extraDistr is adequate for ordinary log densities, but publishing a fitter whose qml fails near Gumbel requires either an external upstream fix or a demonstrably better external provider. An argument map cannot fix cancellation. A local optimum from evd/ismev/extRemes/mev is not evidence of a global unrestricted MLE.

## Generalized Pareto

### Reference implementations and checks

Let y=x−u≥0, σ>0, t=1+ξy/σ>0. Survival S=t^(−1/ξ), log f=−log σ−(1+ξ)log1p(ξy/σ)/ξ; ξ=0 gives an exponential above u. extraDistr supplies **dgpd/pgpd/qgpd/rgpd**, mapping `mu=u,sigma,xi`. [Source](https://raw.githubusercontent.com/cran/extraDistr/master/src/gpd-distribution.cpp). Dependency/maintenance details are in the shared table.

**Checked here:** the same x/shape grid as GEV gave stable log-density differences ≤4.5×10^−16. Ordinary direct-density powers agreed to ≤2.3×10^−16 away from tiny ξ. At ξ=0, x=1000, log density is correctly −1000; at ξ=−0.5, x=2−10^−12 it is −28.3240794. Ordinary p/q composition error was ≤2.2×10^−16 at ξ=−0.75,0,0.3,10, but **5.77×10^−5 at ξ=10^−12**. At ξ=10^−16, qgpd(0.5)=0 instead of approximately 0.693147181. `pgpd(1e-20)` returns zero instead of approximately 10^−20; upper log probability at x=1000, ξ=0 is −Inf instead of −1000. `dgpd(u)` is zero, including the exponential case; `dgpd(u+sigma,xi=-1)` is zero at the uniform upper endpoint. Endpoint conventions materially affect ML fits.

**Source comparison:** evd and POT have all four `*gpd` functions with `loc,scale,shape`; POT additionally has `lambda` in p/q (keep zero for an ordinary conditional GPD). Their direct powers/subtractions and strict endpoint density checks share the relevant weaknesses; no `log.p` support in these p/q interfaces. ismev's `gpd.fit` uses a supplied threshold, not a replacement quartet. extRemes uses its generic quartet with `type="GP"`; p/q/r use `threshold`, while the inspected density standardizes with `loc`, so an argument map must handle these separately. mev has **dgp/pgp/qgp/rgp**, not dgpd: log1p helps density evaluation, but p still subtracts from one, and scalar-shape q still uses powers minus one. Its dgp support handling also needs checking before use outside the proposed restricted shape range. [POT source](https://raw.githubusercontent.com/cran/POT/master/R/GPD-dpqr-fun.R), [mev source](https://raw.githubusercontent.com/cran/mev/master/R/distributions.R). No runtime ranking of uninstalled packages is claimed.

### MLE behaviour and threshold policy

**Derived here:** with u fixed below min x, fix ξ<−1 and set σ=−ξ(M−u+ε). At M the same factor ε^(−1/ξ−1) diverges while the other factors remain finite and positive. Thus unrestricted global ML **never exists for nonconstant samples**, even when the true ξ is regular. Check x=(1,2,3,4), u=0, ξ=−2: log L=−2.98860, 0.46670, 3.92058 for ε=10^−3,10^−6,10^−9.

A closed floor **ξ≥c>−1**, with all y>0, removes that divergence and gives finite attainment: scale collapse and scale explosion lose likelihood, and positive shape going to infinity cannot retain positive likelihood at every strictly positive excess. No uniqueness assertion. **Proposal: c=−1/2**, primarily to keep the first implementation away from the troublesome endpoint region; this deliberately excludes valid −1<ξ<−1/2 models and includes an attained nonregular boundary. A floor c closer to −1 is also defensible for an ML-only package. Smith's regularity threshold alone does not require the stronger floor, and ξ=−1/2 does not acquire ordinary regular inference by being permitted.

If instead using **ξ>−1**, compare the **uniform closure** ξ↓−1, σ→M−u, with log L=−n log(M−u). Under the continuous endpoint version this is uniform on [u,M]. It can beat all interior candidates with positive probability; then D1 should name the **uniform with lower endpoint fixed at u**. Current `mlunif` estimates both endpoints and cannot perform that same constrained fit: blindly saying “Use mlunif(x)” would change the likelihood problem. Either extend its fixable endpoint API in a later implementation task or use a precise named-limit message. With **ξ≥−1**, uniform is an attained member, but extraDistr's zero endpoint density makes exact boundary reporting inconsistent with dml. Do not paper over that with an optimizer tolerance.

**Known or estimated threshold?** For peaks-over-threshold analysis, u is supplied/selected externally; fit already selected exceedances, or y>0 with u=0. This conditional likelihood cannot choose a tail threshold by ML while discarding observations below each proposed u: sample selection and its likelihood change. Threshold diagnostics are a separate task.

For a full shifted GPD sampling model, u may be estimated. At ξ>−1, increasing u toward min x with σ,ξ fixed increases every density (score in u is `(1+xi)/sigma * sum(1/t)`), so under a closed lower-endpoint convention the estimate is **u=min x**. This is a support-boundary estimate, not ordinary regular three-parameter ML. extraDistr excludes that endpoint, giving an unattained supremum for this location direction. Free u also restores positive-shape collapse: choose u=m−aσ, a>0 fixed; then the k minimum observations contribute σ^(−k), others σ^((n−k)/ξ). An upper shape bound/tie guard is needed just as for GEV. Therefore **start with u fixed**, expose it as an explicit fixed location argument (default zero on excesses), and reserve estimated u for a separately guarded extension. Reject observations at/below u with the chosen extraDistr reference; no hidden data filtering.

Exponential ξ=0 is an **included interior member**, not an escape; its closed-form σ=mean(y) is a useful candidate and fixed-shape dispatch. `mlexp(y)` fits excesses, not the shifted observations x directly. For ξ>0 the model is a scaled Lomax after translation (κ=1/ξ, λ=ξ/σ); this overlap is a reparameterization, not another missing limit.

### Fitter sketch and recommendation

Use [Grimshaw (1993), DOI 10.1080/00401706.1993.10485040](https://doi.org/10.1080/00401706.1993.10485040) as the one-dimensional root-search reference; [mev's tutorial](https://lbelzile.github.io/EVA2023-Rtutorial/content/likelihood.html) explicitly compares exponential and uniform cases. For nonzero a=ξ/σ, at a joint interior stationary point `xi(a)=mean(log1p(a*y))`, `sigma(a)=xi(a)/a`, with a>−1/max(y). Enumerate admissible score roots, not just one Newton trajectory; include a=0's exponential separately. This gives the unconstrained profile in a; enforcing the proposed shape floor can move its maximizer to that floor, so constrained-boundary fits must also be compared.

For ξ=−1/2, optimize scale over σ>max(y)/2; more generally fixed ξ has its own one-dimensional scale score. Allow fixed σ and/or ξ as well as mandatory fixed u; use BFGS only if profiling becomes awkward. Starts: exponential scale, moments when finite, and feasible negative/positive shape starts; moments are starts, not restrictions requiring finite theoretical variance. O(n) per evaluation, modest one-dimensional root/grid cost; enforce support and C++ statuses.

**Add now, M**, as a declared fixed-threshold constrained model, with the floor explicitly approved as policy before implementation. The main work is complete root/boundary comparison and fixing external near-zero quantiles/tails. ExtraDistr remains the lowest incremental dependency choice; no inspected alternative is uniformly superior for GPD evaluation. If full-quality qml is a release requirement, its upstream repair is a prerequisite rather than justification for a private quantile function.

## Shifted Gompertz

### Reference implementation and checks

extraDistr supplies **dsgomp/psgomp/rsgomp, no qsgomp**, arguments b>0, η>0, x≥0. Despite documentation calling b a scale, it is a **rate**: F(x)=(1−e^(−bx))exp(−ηe^(−bx)); f=b e^(−bx)exp(−ηe^(−bx))[1+η(1−e^(−bx))]. “Shifted” is the distribution's name; **there is no location parameter**. Its r function takes the maximum of independent Exp(rate b) and Gumbel(location log η/b, scale 1/b). [Documentation](https://rdrr.io/cran/extraDistr/man/ShiftGomp.html), [source](https://raw.githubusercontent.com/cran/extraDistr/master/src/shifted-gompertz-distribution.cpp). Same extraDistr maintenance/dependency assessment as above. The other five named packages provide no shifted-Gompertz quartet identified in this review; VGAM is not a candidate.

**Checked here:** at (x,b,η)=(0.7,2,3), f=0.767319217627612, agreeing with the direct formula; at (100,2,10^−10), f≈2.7677930537502×10^−87, also agreeing. At (1000,1,1), extraDistr log f=**−Inf**, whereas the stable expression `log(b)-b*x-eta*exp(-b*x)+log1p(eta*(-expm1(-b*x)))` gives **−999.306852819440**. At x=10^−20,b=η=1, psgomp=0 rather than approximately e^(−1)10^−20. Upper log probability at x=1000 is −Inf although asymptotically log S≈log(1+η)−bx. Problems come from taking log after exp underflows, and subtracting exp from one.

There is **no external q to round-trip**. As a limited CDF check, numerically inverted psgomp using `uniroot` for p=0.01,0.5,0.99, b=2, η=0.1,1,100; max residual ≤3.8×10^−14. This only checks invertibility in the ordinary range, not independent tail accuracy, and is not a proposed private qml implementation.

### MLE behaviour: derivation and literature

[Jiménez Torres (2014), DOI 10.1016/j.cam.2013.07.004](https://doi.org/10.1016/j.cam.2013.07.004) discusses ML and alternative estimation methods; its abstract reports simulations, not a theorem of universal finite-sample existence. The following existence/boundary analysis is derived here.

Put v_i=e^(−b x_i), a_i=1−v_i. Then

`ell(b,eta) = n*log(b)-b*sum(x)-eta*sum(v)+sum(log1p(eta*a))`.

For fixed b, the η score is `-sum(v)+sum(a/(1+eta*a))`; its derivative is `-sum(a^2/(1+eta*a)^2)<0` for positive data. Thus the constrained η≥0 maximum is uniquely zero if `n-2*sum(v)<=0`, otherwise the unique positive score root. This makes a one-dimensional outer b search practical, without a two-dimensional generic optimizer.

At η↓0 the limit is Exp(rate b). For a strictly positive nonconstant sample, escape directions b↓0, b↑∞ and/or η↑∞ cannot improve the likelihood indefinitely: η↑∞ with b bounded sends mass to infinity; keeping log η/b near the data while b↑∞ collapses the width and loses likelihood on distinct observations. Consequently the closure including η=0 has a finite maximum; **an interior maximum exists only for some samples**, since the exponential face can win. Positive constant samples allow b↑∞, η≈exp(b*x), with f(x)≈b/e and unbounded likelihood. Reject these; zero/rounded observations require separate input treatment, although f(0)=b exp(−η) is a legitimate density value.

The exponential boundary candidate is b0=1/mean(x), ell0=n log b0−n. The inward profile score there is `n-2*sum(exp(-x/mean(x)))`. A positive score rules out a boundary maximum; a nonpositive score establishes only a **local** boundary candidate. Compare the global profiled fit with ell0; do not use this score as an unproved global criterion. If η>0 is the declared family, exponential wins invoke D1 **“Use mlexp”**, declared in `limits`. If η=0 is deliberately included, it is an attained member instead, but extraDistr rejects zero η and cannot evaluate that parameter vector.

For large η, **bX−log η** tends to standard Gumbel. This recentering does not give a finite Gumbel limit for X in the fixed-origin family: with b bounded the location diverges; with b↑∞ and log η/b finite, variance collapses to a point mass. Therefore **do not declare an mlgumbel escape**. Adding a freely fitted location would be a different three-parameter family, requiring new closure/collapse analysis.

### Fitter sketch and recommendation

Estimate rate b and shape η; both could be fixed. Profile η by safeguarded Newton/bisection including its zero boundary; search log b from b≈1/mean(x), plus moment/quantile-scale starts. Evaluate `-expm1(-b*x)` and retain −bx directly in the log density. Each η score iteration costs O(n); nested one-dimensional searches should be cheap for ordinary samples. Compare exponential explicitly and distinguish iteration failure from a winning face with C++ statuses. No uniqueness claim for the joint fit.

**Add later, M.** The likelihood analysis is manageable and d/p/r have an existing light incremental reference, but missing external q blocks a complete qml interface. Issue #7 only required an external density, so a documented qml-unavailable model is possible if existing API policy permits it; do not invent qsgomp inside univariateML. Preferred route is an upstream external q implementation and log-density/tail repairs, followed by the profiled fitter and D1 exponential comparison.
